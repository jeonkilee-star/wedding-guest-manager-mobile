# 결혼식 하객 관리

가족이 각자 휴대폰으로 하객 인원을 입력하면 **실시간으로 합산**되는 웹앱입니다.
앱 설치도, 로그인도 필요 없습니다.

**👉 https://jeonkilee-star.github.io/wedding-guest-manager-mobile/**

예식일: 2026년 9월 19일 · 신랑 이정민 · 신부 김예미

---

## 가족용 사용법

### 1. 처음 열었을 때 — 딱 한 번만

**신랑측 / 신부측**을 고르고, 본인 **역할**을 선택한 뒤 `등록하기`를 누릅니다.

| | 선택할 수 있는 역할 |
|---|---|
| 신랑측 | 신랑 (이정민) · 아버지 · 어머니 · 동생 |
| 신부측 | 신부 (김예미) · 아버지 · 어머니 · 언니 |

이후로는 그 휴대폰이 해당 역할로 기억되어, 다시 열면 **바로 입력 화면**이 나옵니다.

### 2. 하객 추가

1. **메모** — 누구인지 알아볼 수 있게 적습니다 (예: `친구`, `큰아버지댁`, `거래처`)
2. **인원수** — 숫자를 직접 입력하거나 `+` `−` 로 조절합니다
3. `추가하기`

한 번에 다 넣지 않아도 됩니다. 생각날 때마다 나눠서 추가하면 알아서 합산됩니다.

### 3. 현황 보기

입력 칸 아래에 **누구나 볼 수 있는** 현황이 표시됩니다.

- **총 인원 / 신랑측 / 신부측** — 전체 합계
- **역할별 현황** — 신랑측·신부측 탭을 눌러 아버지·어머니·형제자매별 인원을 확인
- **내 제출 내역** — 이 휴대폰에서 넣은 기록. `수정` 으로 숫자·메모를 고치고, `삭제` 로 지웁니다

다른 가족이 입력하면 **새로고침 없이 바로** 숫자가 올라갑니다.

### 4. 역할을 잘못 골랐다면

오른쪽 위 **⚙️** → `역할 변경`. 그 휴대폰의 역할만 다시 정합니다.
이미 입력한 하객 기록은 지워지지 않습니다.

### 5. 화면이 예전 그대로일 때

휴대폰이 옛날 화면을 기억하고 있는 경우입니다. 주소 뒤에 `?v=2` 를 붙여 여세요.

```
https://jeonkilee-star.github.io/wedding-guest-manager-mobile/?v=2
```

## 알아두실 점

> **링크를 아는 사람은 누구나 보고 입력할 수 있습니다.**
> 매번 비밀번호를 넣는 번거로움을 없애려고 일부러 이렇게 만들었습니다.
> 링크는 가족에게만 공유해 주세요.

- **내 제출 내역에는 그 휴대폰에서 넣은 것만** 보입니다. 다른 사람 기록은 수정·삭제할 수 없습니다.
- 다만 **총 인원과 역할별 현황은 모두에게 공개**됩니다.
- 삭제한 기록은 **되돌릴 수 없습니다.**

## 기술 사항

| 항목 | 내용 |
|---|---|
| 구성 | 단일 `index.html` — 프레임워크·빌드 도구 없음 |
| 호스팅 | GitHub Pages (`master` 브랜치에 푸시하면 자동 배포) |
| 데이터베이스 | Firebase Cloud Firestore `wedding-guests-21e70` (서울 리전, 무료 Spark 요금제) |
| 실시간 반영 | Firestore `onSnapshot` 구독 |
| 기기 기억 | `localStorage` 에 선택한 역할 저장 |

### 데이터 구조

`submissions` 컬렉션에 입력 1건당 문서 1개가 쌓입니다.

```js
{
  contributor: "신랑측 아버지",   // 표시용 이름
  userSide:    "groom",          // groom | bride
  userRole:    "아버지",          // 집계 기준
  count:       4,                // 인원수
  personalNote: "거래처",         // 메모
  createdAt:   1757400000000,    // 입력 시각
  deviceId:    "dev_xxx_yyy"     // 입력한 기기 (내 제출 내역 판별용)
}
```

`deviceId` 가 없는 문서는 기기 ID 도입(2026-09-10) 이전 기록으로,
`userSide` + `userRole` 이 일치하면 본인 것으로 간주합니다.

### 보안 규칙

`submissions` 컬렉션만, **2027-03-31까지** 열려 있습니다.

```
match /submissions/{docId} {
  allow read: if request.time < timestamp.date(2027, 3, 31);
  allow create, update, delete: if request.time < timestamp.date(2027, 3, 31);
}
```

> ⚠️ 이 날짜가 지나면 앱이 조용히 "이 기기에만 저장됨" 모드로 바뀝니다.
> 이후에도 계속 쓰려면 Firebase 콘솔에서 규칙의 날짜를 연장해야 합니다.

### 데이터 백업

`backups/` 폴더에 JSON으로 보관합니다. 하객 이름·메모가 들어가므로
`.gitignore` 로 제외되어 있어 **공개 저장소에는 올라가지 않습니다.**

### 연결 상태 확인

앱 화면의 현황 위에 상태가 표시됩니다.

| 표시 | 의미 |
|---|---|
| 🔄 가족과 실시간 공유 중 | 정상 |
| 📱 이 기기에만 저장됨 | Firebase 미설정 — 다른 가족에게 전달되지 않음 |
| ⚠️ 연결 실패 | 규칙 만료 또는 네트워크 문제 |
