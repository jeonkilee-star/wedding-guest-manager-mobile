# 결혼식 하객 관리 웹앱

모바일 최적화된 결혼식 하객 인원 관리 도구입니다. 가족들이 각자 다른 기기에서 실시간으로 하객을 등록하고 관리할 수 있습니다.

## 주요 기능

### 입력 (상단)
- **탭으로 빠른 선택**: 신랑측/신부측 선택
- **역할 버튼**: 
  - 신랑측: 신랑, 아버지, 어머니, 동생
  - 신부측: 신부, 아버지, 어머니, 언니
- **인원수 관리**: +/− 버튼으로 간편 조작
- **개인 메모**: 입력자만 알 수 있는 기록 (예: "친구 3명")

### 목록 (하단)

#### 공개 목록 탭
- 모든 가족이 볼 수 있는 목록
- 작성자 + 인원 + 상태(미응답/참석/불참)만 표시
- 개인 이름은 절대 보이지 않음

#### 내 제출 탭 (입력자만 볼 수 있음)
- 자신이 입력한 모든 기록
- 입력자별 총 인원수 표시 (예: "신랑측 아버지 (총 15명)")
- 개인 메모 포함
- 수정/삭제 가능

### 통계 (실시간)
- 총 인원
- 제출 건수
- 참석 인원
- 미응답 인원

## 사용 방법

### 로컬 사용
1. `index.html` 파일을 웹 브라우저에서 엽니다
2. 데이터는 브라우저 로컬 스토리지에 저장됩니다

### 가족과 공유 (온라인)
1. 이 파일을 웹 서버에 배포합니다
2. 링크를 가족에게 공유합니다
3. 각자 다른 기기에서 접속하면 실시간으로 동기화됩니다

## 데이터 저장

### 공개 데이터
- **저장 위치**: 클라우드 데이터베이스
- **공개 범위**: 모든 사용자가 볼 수 있음
- **내용**: 작성자 + 인원 + 상태

### 개인 기록
- **저장 위치**: 클라우드 (사용자별 격리)
- **공개 범위**: 입력자만 볼 수 있음
- **내용**: 개인 메모 포함 모든 정보

## 팁

- **탭 유지**: 신랑측/신부측과 역할(예: 아버지)을 선택하면 계속 유지됩니다. 이름만 바꾸면 됩니다
- **키보드**: 이름 입력할 때만 키보드가 나타나므로 모바일에서 편합니다
- **상태 관리**: 공개 목록에서 각 항목의 상태를 실시간으로 변경할 수 있습니다
- **프라이버시**: 공개 목록에는 개인 이름이 나타나지 않으므로 누구나 볼 수 있어도 안전합니다

## 기술 사항

- **프레임워크**: 순수 HTML/CSS/JavaScript (의존성 없음)
- **저장소**: 로컬 스토리지 + 클라우드 DB (선택)
- **오프라인**: 인터넷이 없어도 로컬에서 작동
- **반응형**: 모든 기기에서 최적화된 UI
- **PWA**: 모바일 앱처럼 설치 가능 (지원 브라우저)
